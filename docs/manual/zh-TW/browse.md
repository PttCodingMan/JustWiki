# 搜尋與瀏覽

## 全文搜尋

按 `Ctrl+K`（macOS 為 `⌘K`）或頂端的搜尋圖示開啟搜尋框，輸入關鍵字即時列出結果；按 Enter 進入完整的搜尋結果頁，可再用標籤篩選。

- 搜尋標題與內文，結果會顯示命中段落並標示關鍵字
- 使用 SQLite FTS5 全文索引，原生支援中日韓文字，不需要先斷詞
- 只會搜到你有權閱讀的頁面

:::tip
在這個 demo 站試試看：搜尋「備份」或「ACL」。
:::

## 關係圖（Graph）

![3D 知識圖譜](/api/media/graph-3d.png)

側邊欄的 **關係圖** 會把所有頁面畫成節點，wikilink 畫成連線，方便看出哪些頁面是核心、哪些是孤島。

- 支援 3D 與平面兩種模式；瀏覽器不支援 WebGL 時自動改用 2D
- 點選節點可看連結數並前往該頁

## 最近變更

側邊欄的 **最近變更** 顯示整個 wiki 的時間軸：誰建立、更新、刪除或驗證了哪一頁，並統計頁面總數、使用者數與熱門頁面。

## 書籤

在任何頁面按書籤圖示，該頁就會出現在側邊欄的 **書籤** 區，適合放每天都要開的頁面。書籤是個人的，別人看不到。

## 主題與字體

![9 款內建主題](/api/media/themes.png)

右上角的主題選單內建 9 款配色：**明亮、深色、薰衣草、森林、玫瑰、海洋、沙地、日落、北歐**，另外可以把內文字體切換為等寬字體。選擇會記在瀏覽器裡。

## 介面語言

右上角的語言選單可切換 **English、繁體中文、日本語、한국어**。語言只影響介面文字，不會翻譯頁面內容。

## 匯出單頁

在頁面的 **⋯ 更多操作** 裡：

- **複製 Markdown / 下載 .md** — 取得原始 Markdown
- **匯出 HTML** — 單一 HTML 檔，方便寄送或封存
- **列印 / 另存為 PDF** — 開啟瀏覽器列印對話框，選「另存為 PDF」即可

整個 wiki 打包匯出請看 [[zh-admin|管理員指南]]。
