# 整理頁面

## 頁面階層

頁面可以無限巢狀，不像 BookStack 只有 Book → Chapter → Page 三層。左側頁面樹會以樹狀顯示所有你有權閱讀的頁面：

- 在某頁的 **頁面選項** 選 **新增子頁面**，新頁面就會建在它底下
- 直接在頁面樹裡拖曳頁面，就能換位置或換父頁面
- 子頁面預設繼承父頁面的權限（見 [[zh-permissions|權限與帳號]]），所以把頁面搬到別的分支時，可讀的人也可能跟著改變

建議用頂層頁面區分大類（例如「產品」「工程」「營運」），再往下分專案或主題。你現在看的這份手冊就是一個例子：中英文各一個目錄頁，底下掛各章節。

## 標籤

標籤適合跨越樹狀結構的分類，例如 `onboarding`、`runbook`、`deprecated`：

- 在頁面上方按 **+ 標籤** 新增，點標籤旁的 × 移除
- 搜尋結果頁可以用標籤篩選，只看某一類頁面

## 範本

新增頁面時可以選範本，讓團隊文件格式一致。系統內建四個：

| 範本 | 用途 |
|------|------|
| 會議記錄 | 議程、討論、決議、待辦事項 |
| 技術文件 | 概述、架構、API、注意事項 |
| Troubleshooting | 症狀、原因、排除步驟 |
| ADR | 架構決策紀錄（Architecture Decision Record） |

管理員可在 **管理 → 範本** 新增、修改或刪除範本，整個團隊共用同一組。

## 頁面類型

建立頁面時可以選擇類型：

- **📄 文件** — 一般的 Markdown 頁面
- **🧠 心智圖** — 用 Markdown 標題或項目清單撰寫，畫面會渲染成心智圖。讀者可以切換配色主題與佈局（向右展開、向左展開、放射狀）

心智圖的實際效果請看 [[zh-mindmap|心智圖頁面範例]]。

## 刪除與回收桶

刪除頁面不會立刻消失，而是移到 **回收桶**（側邊欄入口）：

- 原作者或管理員可以把頁面還原，還原後搜尋索引與反向連結會自動重建
- 只有管理員能永久刪除
