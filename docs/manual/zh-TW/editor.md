# 編輯器

JustWiki 的編輯器是所見即所得（WYSIWYG）的 Milkdown，打字時看到的就是最終排版；但底層存的仍是純 Markdown。非工程師可以直接寫，工程師也能用 Git、腳本或 API 處理內容，資料不會被綁在專屬格式裡。

## Slash 指令

![Slash 指令選單](/api/media/slash-commands.png)

在編輯器輸入 `/` 會跳出插入選單，繼續打字可即時篩選，按 ↑ ↓ 選擇、Enter 插入。

| 指令 | 說明 |
| ---- | ---- |
| `/h1` `/h2` `/h3` | 標題 1 / 2 / 3 |
| `/bullet` | 項目清單 |
| `/ordered` | 編號清單 |
| `/quote` | 引用區塊 |
| `/code` | 程式碼區塊 |
| `/hr` | 分隔線 |
| `/callout-info` | 資訊提示框（`:::info`） |
| `/callout-warning` | 警告提示框（`:::warning`） |
| `/callout-tip` | 小提示框（`:::tip`） |
| `/callout-danger` | 危險提示框（`:::danger`） |
| `/mermaid` | Mermaid 圖表 |
| `/math` | KaTeX 數學區塊 |
| `/drawio` | Draw.io 圖表 |
| `/media` | 從媒體庫挑選已上傳的檔案 |

每種區塊的寫法與效果請看 [[zh-rich-content|豐富內容]]。

## Markdown 語法

JustWiki 支援 GitHub Flavored Markdown（GFM）。在編輯器裡直接打 Markdown 也會即時轉成排版，例如行首打 `## ` 就變成標題。

| 語法 | 效果 |
|------|------|
| `**粗體**` | **粗體** |
| `*斜體*` | *斜體* |
| `~~刪除線~~` | ~~刪除線~~ |
| `` `行內程式碼` `` | `行內程式碼` |
| `[連結文字](https://example.com)` | [連結文字](https://example.com) |
| `![說明](圖片網址)` | 圖片 |

清單與待辦事項：

```
- 項目
  - 巢狀項目
1. 編號項目
- [x] 已完成
- [ ] 待辦
```

- [x] 已完成
- [ ] 待辦

表格：

```
| 欄位 A | 欄位 B |
|--------|--------|
| 資料 1 | 資料 2 |
```

| 欄位 A | 欄位 B |
|--------|--------|
| 資料 1 | 資料 2 |

## 圖片與檔案

- **貼上上傳** — 截圖後直接在編輯器 `Ctrl+V`，圖片會自動上傳並插入
- **媒體庫** — 用 `/media` 從已上傳的檔案中挑選，同一張圖可以在多頁重複使用
- **大小上限** — 預設單檔 20 MB，管理員可在 **管理 → 網站設定** 調整（1–100 MB）

系統會追蹤每個媒體檔被哪些頁面引用，管理員在媒體庫就能看出哪些檔案已沒人使用。

## 草稿自動儲存

編輯中的內容會持續存在 **你這台瀏覽器** 裡。關掉分頁、瀏覽器當機或電腦重開後，再次編輯同一頁時會出現「找到未儲存的草稿」，可以選擇 **還原草稿** 或 **捨棄草稿**。

:::warning
草稿只存在本機瀏覽器，不會同步到伺服器或其他裝置。如果在你離開之後別人已經修改過這頁，畫面會標示草稿所根據的版本與目前版本，儲存時會請你處理衝突（見 [[zh-collaboration|協作]]）。
:::

## 頁面上的其他編輯

不用進入編輯模式也能做的事：

- **標籤** — 頁面上方按 **+ 標籤** 新增，點標籤上的 × 移除
- **書籤** — 按書籤圖示加入或移除
- **複製 / 下載 Markdown** — 在 **⋯ 更多操作** 裡，方便貼到別處或交給腳本
