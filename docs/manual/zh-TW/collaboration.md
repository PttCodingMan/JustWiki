# 協作

## 留言討論

每頁底部都有 **討論** 區，適合對內容提問、回報過時資訊或討論修改方向。留言支援 Markdown 與 @提及（見 [[zh-links|連結與嵌入]]），作者可以編輯或刪除自己的留言。

## 追蹤頁面與通知

在頁面上按 **追蹤頁面**，之後這頁被別人更新、刪除，你都會在右上角的通知鈴鐺看到。頁面上會顯示目前有幾個人在追蹤。

會出現在通知裡的事件：

- 你追蹤的頁面被別人建立、更新或刪除
- 你在頁面或留言中被 @提及
- 你負責複查的頁面到期（見下方「定期複查」）

:::info
如果某頁之後被設了權限而你已經看不到它，就不會再收到這頁的通知，避免標題外洩。
:::

## 版本歷史

每次儲存都會建立一個新版本。在頁面上按 **歷史** 可以：

- 瀏覽所有版本與修改者
- 勾選任意兩個版本比較差異（diff）
- **還原** 到某個舊版本——還原前會先把目前內容另存成新版本，所以還原本身也能再還原

## 同時編輯的保護

兩個人同時編輯同一頁時，先儲存的人正常存檔；後儲存的人不會默默蓋掉對方，而是看到衝突提示，畫面會列出版本差異，讓你把自己的修改合併到最新版後再存。

這個機制叫樂觀鎖（optimistic locking）：每次儲存都要帶上「我是根據第幾版改的」，伺服器發現版本已經變了就回 409 Conflict。透過 API 編輯時也一樣，見 [[zh-developer|開發者指南]]。

## 草稿自動儲存

編輯中的內容會自動存在瀏覽器，關掉分頁或當機後回來可以還原。詳見 [[zh-editor|編輯器]]。

## 定期複查

文件寫完之後最常見的問題是「過時了但沒人知道」。定期複查讓每頁都可以指定負責人和週期：

1. 在頁面的 **⋯ 更多操作 → 複查設定** 開啟複查
2. 選擇複查週期（每 N 天），並指定負責人（選填，未指定則由頁面建立者負責）
3. 負責人確認內容仍正確後，按 **標記為已驗證**，週期就重新起算

頁面上會顯示「X 天後需複查」「已逾期 X 天」以及最後驗證日期，讀者一眼就知道這頁可不可信。到期時負責人會收到通知（也可以透過 Webhook 送到 Slack 等外部服務）。

側邊欄的 **文件複查** 列出所有開啟複查的頁面，最急的排最前面，可以切換「全部」或「我負責的」。

## 最近變更

側邊欄的 **最近變更** 是整個 wiki 的動態時間軸，見 [[zh-browse|搜尋與瀏覽]]。
