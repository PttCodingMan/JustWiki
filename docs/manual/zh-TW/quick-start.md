
# 快速上手

這頁帶你在五分鐘內寫出第一頁，並認識介面。

## 介面導覽

![主介面](/api/media/hero.png)

- **左側邊欄** — 頁面樹、書籤，以及最近變更、關係圖、AI 對話、文件複查、回收桶等入口
- **中央** — 頁面內容；上方是編輯、歷史、追蹤、書籤與 **⋯ 更多操作**（匯出、權限、公開、複查設定、刪除…）
- **右側** — 目錄（TOC），依頁面標題自動產生，點擊即可跳轉
- **頂端列** — 新增頁面、搜尋、通知鈴鐺、主題選單、語言切換、個人選單

## 寫出第一頁

1. 按頂端的 **新增頁面**，或按 `Ctrl+N`
2. 選擇頁面類型：**📄 文件** 或 **🧠 心智圖**
3. 選擇從空白頁面開始，或套用一個範本（會議記錄、技術文件、ADR…）
4. 輸入標題後按 **建立**，接著在編輯器裡打字，或輸入 `/` 叫出插入選單
5. 按 **儲存**，頁面就會出現在頁面樹裡

想建立子頁面，在頁面樹中某頁的 **頁面選項** 選 **新增子頁面** 即可；已經建好的頁面也能在頁面樹裡拖曳到別的父頁面底下。

:::tip
頁面網址是系統自動產生的短代碼（例如 `/page/aB3xK9pQ`），之後改標題、搬移位置都不會讓連結失效。
:::

## 編輯既有頁面

在頁面上按 **編輯** 或 `Ctrl+E` 進入編輯模式。編輯中的內容會自動存在瀏覽器，萬一關掉分頁或當機，下次打開會提示你還原草稿，詳見 [[zh-editor|編輯器]]。

同一頁被兩個人同時編輯時，後儲存的人會看到衝突提示，而不是默默蓋掉對方的修改，詳見 [[zh-collaboration|協作]]。
