# 連結與嵌入

Wiki 的價值在於頁面彼此連得起來。JustWiki 提供三種串連方式：Wikilink、Transclusion 和 @提及。

## Wikilinks

![輸入雙方括號觸發頁面搜尋](/api/media/wikilink.png)

在編輯器輸入 `[[` 會跳出頁面搜尋，繼續打字篩選，按 ↑ ↓ 選擇、Enter 插入。插入後的語法是：

```
[[page-slug]]
[[page-slug|自訂顯示文字]]
```

例如這個連結會回到 [[zh-guide|手冊目錄]]。

連結指向的是頁面的 slug（網址代碼），所以之後改標題或搬移頁面位置，連結都不會壞。

## 反向連結（Backlinks）

每次儲存時，系統會解析頁面裡的 wikilink，自動記錄「誰連到誰」。在頁面底部的 **被引用於** 區塊可以看到所有連到這頁的頁面——往下捲就會看到這頁被哪些手冊頁面引用。

反向連結也是 [[zh-browse|關係圖]] 的資料來源。

## Transclusion（嵌入其他頁面）

在 wikilink 前面加一個驚嘆號，就會把另一頁的內容就地嵌入：

```
![[page-slug]]
![[page-slug|自訂標題]]
```

嵌入的是即時內容，來源頁更新時所有嵌入處都會跟著更新。常見用法：

- 把共用段落（聯絡窗口、環境清單、快捷鍵表）寫成一頁，再嵌入到需要的地方
- 做一個「總覽頁」，把多個子頁的重點彙整起來

[[zh-quick-start|快速上手]] 裡的快捷鍵表，就是從 [[zh-shortcuts|鍵盤快捷鍵]] 頁嵌入的。下面再嵌一次給你看：

## @提及

在頁面或留言裡輸入 `@` 會跳出使用者清單：

- `@使用者名稱` — 提及某位使用者，顯示為連到對方個人頁面的連結
- `@@群組名稱` — 提及整個群組

被提及的人（群組則是群組成員）會在通知鈴鐺收到提醒；看不到這一頁的人不會被通知。個人簡介裡也能用 @提及 與 wikilink。
