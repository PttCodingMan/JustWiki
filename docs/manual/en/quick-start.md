# Quick Start

Write your first page and get to know the UI in five minutes.

## A tour of the UI

![Main UI](/api/media/hero.png)

- **Left sidebar** — the page tree, bookmarks, and entries for Recent Changes, Graph View, AI Chat, Reviews and Trash
- **Center** — the page itself; above it are Edit, History, Watch, Bookmark and **⋯ More actions** (export, permissions, public sharing, review settings, delete…)
- **Right** — the table of contents, built from the page's headings
- **Top bar** — New Page, Search, the notification bell, theme menu, language switcher and your profile menu

## Your first page

1. Click **New Page** in the top bar, or press `Ctrl+N`
2. Pick a page type: **📄 Document** or **🧠 Mindmap**
3. Start from a blank page or a template (Meeting Notes, Tech Doc, ADR…)
4. Enter a title and click **Create**, then type in the editor — or type `/` to open the insert menu
5. Click **Save** and the page shows up in the page tree

To create a sub-page, open a page's **Page actions** in the tree and choose **New subpage**. Existing pages can be dragged in the tree to reorder them or move them under another parent.

:::tip
Page URLs use a short generated code (such as `/page/aB3xK9pQ`), so renaming or moving a page never breaks links to it.
:::

## Editing a page

Click **Edit** or press `Ctrl+E`. Your changes are autosaved in the browser, so if you close the tab or crash you will be offered the draft next time — see [[en-editor|The Editor]].

When two people edit the same page at once, whoever saves second gets a conflict prompt instead of silently overwriting the other — see [[en-collaboration|Collaboration]].
