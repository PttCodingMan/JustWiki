# 從這裡開始 · Start Here

這是 JustWiki 的唯讀 demo：介面就是真正的 JustWiki，內容是它的使用手冊。瀏覽、搜尋、關係圖、主題與語言切換都能直接操作；需要登入或伺服器的功能（編輯、留言、AI 問答、匯出）在這裡停用。

This is a read-only demo of JustWiki: the UI is the real app, and the content is its user guide. Browsing, search, the graph and theme or language switching all work; anything that needs a sign-in or a server (editing, comments, AI chat, export) is disabled here.

## 第一次來？· New here?

- **English** — start with [[en-quick-start|Quick Start]] for a five-minute tour of the UI and the writing flow; to see who JustWiki is for, read the top of the [[en-guide|User Guide]].

## 在 demo 裡試試看 · Things to try

- **搜尋 · Search** — 按 `Ctrl+K`（macOS 為 `⌘K`），輸入「權限」或 `mermaid`。 / Press `Ctrl+K` (`⌘K` on macOS) and type `mermaid` or `permissions`.
- **關係圖 · Graph View** — 側邊欄的「關係圖」把頁面之間的連結畫成互動圖。 / Graph View in the sidebar draws every link between pages as an interactive graph.
- **主題與語言 · Themes & language** — 右上角的調色盤換主題，地球圖示換介面語言。 / The palette icon at the top right switches themes; the globe switches the UI language.
- **豐富內容 · Rich content** — [[zh-rich-content|豐富內容]] / [[en-rich-content|Rich Content]] 裡有 Mermaid、KaTeX 與提示框的實際渲染。 / See Mermaid, KaTeX and callouts rendered live.
- **心智圖 · Mindmap** — [[zh-mindmap|心智圖頁面]] / [[en-mindmap|Mindmap Page]] 是由一份 Markdown 大綱即時畫出來的。 / A mindmap drawn on the fly from a plain Markdown outline.
- **嵌入與反向連結 · Embeds & backlinks** — [[zh-quick-start|快速上手]] / [[en-quick-start|Quick Start]] 裡的快捷鍵表是從另一頁嵌入的；每頁底部的「被引用於」列出連到該頁的頁面。 / Its shortcut table is embedded from another page, and "Linked from" at the bottom of each page lists the pages that link to it.
